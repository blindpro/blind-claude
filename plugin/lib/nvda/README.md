# NVDA controller client

These are the official NVDA controller client libraries from NV Access, version 2026.2, taken unchanged from `nvda_2026.2_controllerClient.zip` at download.nvaccess.org. One folder per processor type: x64, x86 and arm64.

The speech server loads the one that matches its own process to speak through NVDA. They are licensed under the GNU Lesser General Public License version 2.1, in `license.txt` beside this file.
